## Student Information

**Name:** Salman

## Project Description

This project is a Sleep Debt Calculator built using JavaScript. It calculates the total number of hours slept during a week and compares it with the ideal amount of sleep needed. The program then tells the user whether they got enough sleep, too much sleep, or need more rest.

## Features

* Stores sleep hours for each day of the week
* Calculates total weekly sleep hours
* Calculates ideal weekly sleep hours
* Compares actual sleep with ideal sleep
* Displays a message showing sleep debt or extra sleep

## Technologies Used

* JavaScript
* Functions
* Switch Statements
* Conditional Statements (if/else)

## How to Run

1. Download or clone the project.
2. Open the project in a code editor such as VS Code.
3. Open the terminal.
4. Run the JavaScript file using:

```bash
node sleepDebtCalculator.js
```
